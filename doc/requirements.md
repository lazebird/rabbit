# Rabbit 项目详细需求与特性文档

## 1. 项目概述

### 1.1 项目定位
Rabbit 是一个 Windows 平台的小工具集合，旨在整合程序员常用的零散小工具（如 tftpd、hfs、ping 等），通过统一的 UI 和单一可执行程序解决工具碎片化问题。

### 1.2 设计目标
1. **统一代码库**：一套代码解决项目开发碎片化问题
2. **开源可持续**：确保代码可由任何人维护和更新
3. **统一 UI**：单一可执行程序，解决界面碎片化问题

### 1.3 技术栈
- **运行时**：.NET Framework 4.7.2
- **UI 框架**：Windows Forms
- **语言**：C#
- **构建工具**：MSBuild + ILMerge（合并 DLL 为单一 EXE）

## 2. 功能模块详细规格

### 2.1 Ping 模块 (`lazebird.rabbit.ping`)

#### 2.1.1 功能描述
网络连通性测试工具，支持任务栏状态显示。

#### 2.1.2 配置项
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| addr | string | - | 目标地址（IP 或域名） |
| interval | int | 1000 | Ping 间隔（毫秒），同时作为超时时间 |
| count | int | -1 | 发送次数，-1 表示持续 ping |
| stoponloss | bool | false | 丢包时是否停止 |
| taskbar | bool | true | 是否在任务栏显示状态 |
| log | string | "" | 日志文件路径，为空则不写文件 |

#### 2.1.3 界面元素
- 地址输入框
- 选项输入框（分号分隔的 key=value 格式）
- 开始/停止按钮
- 日志显示区域（ListBox）
- 状态统计显示

#### 2.1.4 任务栏集成
- 非运行时标题显示Rabbit，运行时标题显示ping的地址
- 运行时显示进度状态，规则如下：
  - 取最近5次的结果用于计算，不足5次则取实际次数
  - 取中的结果全部成功，则背景色绿色，进度值为结果数/5
  - 存在失败结果则背景色为红色，进度值为失败次数/5

### 2.2 IP 扫描模块 (Scan)

#### 2.2.1 功能描述
使用 ping 检测 IP 地址是否被占用。

#### 2.2.2 配置项
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| ipstart | string | - | 起始 IP 地址（完整 IP） |
| ipend | string | - | 结束 IP 的最后一位数值 |
| filter | bool | true | true 仅显示可达 IP，false 显示所有 |

---

### 2.3 HTTP 服务器模块 (`lazebird.rabbit.http`)

#### 2.3.1 功能描述
轻量级 HTTP 文件服务器，支持虚拟文件系统。

#### 2.3.2 配置项
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| port | int | 8000 | HTTP 服务端口 |
| shell | bool | false | 是否启用右键菜单集成 |
| autoindex | bool | false | 是否启用目录自动索引 |
| videoplay | bool | false | 视频文件是否启用播放器 |

#### 2.3.3 界面元素
- 端口输入框
- 选项输入框
- 开始/停止按钮
- 目录列表（支持添加/删除）
- 日志显示区域

#### 2.3.4 MIME 类型支持
默认支持：`.svg`, `.html`, `.htm`, `.js`, `.css`, `.mp4`, `.mpeg`, `.avi`, `.mp3`, `.mid`, `.jpg`, `.jpeg`, `.img`, `.ico`, `.png` 等

#### 2.3.5 右键菜单集成
启用后，可在文件/文件夹右键菜单中添加 "Add to Rabbit.http" 选项。

---

### 2.4 TFTP 服务器模块 (`lazebird.rabbit.tftp`)

#### 2.4.1 功能描述
TFTP 文件传输服务器，支持多目录、高并发传输。

#### 2.4.2 配置项
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| port | int | 69 | TFTP 服务端口（UDP） |
| timeout | int | 200 | 接收超时（毫秒） |
| maxretry | int | 10 | 消息重传次数 |
| blksize | int | 512 | 块大小（字节） |
| qsize | int | 2000 | 文件读写队列大小 |
| qtout | int | 1000 | 队列超时（毫秒） |
| override | bool | false | 是否允许覆盖文件 |
| fslog | bool | false | 是否打印文件系统日志 |

#### 2.4.3 界面元素
- 工作目录列表（点击选择当前目录，双击修改路径）
- 添加目录按钮（+）
- 删除目录按钮（-）
- 选项输入框
- 日志显示区域

#### 2.4.4 性能指标
根据测试数据，传输 110MB 文件：
- sRabbit TFTP: ~1.37 MBps
- YaTFTPSvr: ~0.5 MBps

## 4. 选项格式规范

所有模块的选项使用统一的字符串格式：

```
key1=value1;key2=value2;key3=value3
```

解析方法：
```csharp
Hashtable opts = ropt.parse_opts("interval=1000;count=10");
```

## 5. 界面交互规范

### 5.1 通用规则
- Esc 键：退出当前窗口
- Enter 键：执行当前标签的开始/停止按钮
- 双击：复制日志项 / 选择文件 / 导出计划项
- 单击：选择列表项

### 5.2 配置持久化
- 配置文件路径：`%userprofile%\appdata\local\Rabbit\`
- 自动保存：部分配置项支持自动保存
- 手动保存：程序退出时统一保存

### 6.1 构建步骤
1. Pre-build: `tools/svgen.exe` 生成版本信息
